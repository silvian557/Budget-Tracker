# Python Budget Tracker (CLI)

A simple and interactive command-line application built in Python to help users manage their personal budget and keep track of daily expenses.

## Features
- **Initial Budget Setup:** Securely sets up your starting budget with error handling (`try/except`) to prevent crashes from invalid inputs.
- **Expense Tracking:** Allows you to add expenses and automatically subtracts them from your remaining budget.
- **Financial Overview:** View your remaining balance and total spent at any time.
- **Continuous Menu:** Runs smoothly in a loop until you choose to exit.
